# NorChain Whitepaper v2.0 - Word Formatting Guide

This guide provides detailed instructions for formatting the NorChain Whitepaper in Microsoft Word for investor-ready presentation.

---

## Document Setup

### Page Layout
- **Page Size**: A4 (210mm × 297mm)
- **Margins**: Top 2.5cm, Bottom 2.5cm, Left 3cm, Right 2.5cm
- **Orientation**: Portrait
- **Columns**: Single column (except executive summary which can be 2 columns)

### Master Font Settings
- **Primary Font**: Calibri (Body)
- **Monospace Font**: Consolas (for code/addresses)
- **Line Spacing**: 1.15 (standard)
- **Paragraph Spacing**: 6pt after each paragraph

### Title Page
```

- Alignment: Center
- Spacing: 12pt after

Tagline: "Illuminating the Future of Compliant Finance"
- Font: Calibri Italic
- Size: 14pt
- Color: Medium Gray (#6C757D)
- Alignment: Center
```

### Section Headings

#### Level 1 (Major Sections)
```
Font: Calibri Bold
Size: 24pt
Color: NorChain Blue (#0066CC)
Spacing: 18pt before, 12pt after
Numbering: "1. Introduction", "2. Technical Architecture", etc.
Border: 2pt bottom border in NorChain Blue
```

#### Level 2 (Subsections)
```
Font: Calibri Bold
Size: 18pt
Color: NorChain Dark (#1A2335)
Spacing: 14pt before, 8pt after
Numbering: "1.1 The Problem", "2.1 Core Specifications", etc.
```

#### Level 3 (Sub-subsections)
```
Font: Calibri Semibold
Size: 14pt
Color: NorChain Dark (#1A2335)
Spacing: 10pt before, 6pt after
Numbering: Optional (use for deep sections only)
```

### Body Text
```
Font: Calibri (Body)
Size: 11pt
Color: NorChain Dark (#1A2335)
Line Spacing: 1.15
Alignment: Justify (with hyphenation)
First Line Indent: 0 (no indent, use spacing between paragraphs)
```

### Lists

#### Bullet Points
```
Symbol: • (solid circle)
Indentation: 0.5cm from left margin
Hanging Indent: 0.75cm
Font: Same as body text (11pt Calibri)
Spacing: 3pt between items
```

#### Numbered Lists
```
Format: "1. ", "2. ", "3. " (period after number)
Indentation: Same as bullets
```

### Emphasis
```
Bold: Calibri Bold (for key terms, first mention)
Italic: Calibri Italic (for definitions, foreign terms)
Bold Italic: Calibri Bold Italic (for critical warnings/notes)
```

## Table Formatting

### Standard Tables
```
Border: 1pt solid, Border Gray (#DEE2E6)
Header Row:
  - Background: Light Gray (#F8F9FA)
  - Font: Calibri Bold, 11pt
  - Color: NorChain Dark (#1A2335)
  - Alignment: Left (text) or Right (numbers)

Data Rows:
  - Font: Calibri Regular, 10pt
  - Color: NorChain Dark (#1A2335)
  - Alternating Row Shading: None (or very light gray RGB(252,252,252))
  - Padding: 6pt all sides

Column Widths: Auto-fit to content with maximum page width
```

### Financial Tables (Tokenomics, Revenue)
```
Number Format: Use thousand separators (1,000,000)
Currency: Use $ symbol with 2 decimal places ($0.0001)
Percentages: Show with % symbol (40%)
Alignment: Right-align all numbers
Bold: Total rows and key metrics
```

### Comparison Tables
```
Highlight Advantages: Light green background RGB(232,245,233)
Highlight Disadvantages: Light red background RGB(255,235,238)
Neutral Items: White background
```

## Print & PDF Settings

### Print Quality
```
Resolution: 300 DPI minimum
Color Mode: Full color (CMYK for professional printing)
Paper: A4 (210 × 297 mm)
Bleed: 3mm on all sides (for professional printing)
```

### PDF Export Settings
```

Embed Fonts: Yes (all fonts)
Image Quality: High (300 DPI)
Hyperlinks: Preserve
Bookmarks: Create from headings
Security: Optional password protection
Compression: Medium (balance quality and size)
```

## Accessibility Considerations

### Alt Text
- Add descriptive alt text for all images, charts, logos
- Format: Brief description (max 125 characters)

### Heading Structure
- Use proper heading hierarchy (H1 → H2 → H3)
- Never skip heading levels
- Ensure screen reader compatibility

### Hyperlinks
- Use descriptive link text (not "click here")
- Ensure all links are functional
- Color contrast: Minimum 4.5:1 ratio

### Language
- Set document language to English (US)
- Use clear, professional terminology
- Define acronyms on first use

## Conversion Instructions

### From Markdown to Word

**Method 1: Pandoc (Recommended)**
```bash
pandoc NORCHAIN_WHITEPAPER_V2.md -o NorChain_Whitepaper_v2.0.docx \
  --reference-doc=norchain-template.docx \
  --toc --toc-depth=2
```

**Method 2: Copy-Paste + Manual Formatting**
1. Copy markdown content
2. Paste into Word (keep text only)
3. Apply styles using this guide
4. Insert tables manually
5. Format code blocks with Consolas font
6. Add colors using color codes in this guide

**Method 3: Online Converter**
- Use https://pandoc.org/try/
- Upload markdown file
- Download as .docx
- Apply formatting manually

## Template Creation

### Creating a Word Template

1. **Open new Word document**
2. **Define Styles** (Home → Styles → Manage Styles):
   - Create "NorChain Heading 1" style
   - Create "NorChain Heading 2" style
   - Create "NorChain Body" style
   - Create "NorChain Code" style
   - Create "NorChain Callout" style

3. **Set Theme Colors** (Design → Colors → Customize):
   - Accent 1: NorChain Blue (#0066CC)
   - Accent 2: NorChain Gold (#FFB81C)
   - Accent 3: Success Green (#28A745)
   - Text/Background - Dark 1: NorChain Dark (#1A2335)

4. **Save as Template**: File → Save As → "NorChain Whitepaper Template.dotx"
