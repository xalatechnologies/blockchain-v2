


## ❓ Common Issues

### Issue 1: "Compiler version mismatch"
**Fix**: Make sure you select **v0.8.20+commit.a1b79de6** (exact version)

### Issue 2: "Bytecode mismatch"
**Fix**:
- Verify optimization is set to **Yes** with **200** runs
- Check that flattened source includes ALL OpenZeppelin imports
- Regenerate flattened file: `npx hardhat flatten contracts/tokens/NOR_BSC.sol > NOR_BSC_flattened.sol`

### Issue 3: "Constructor arguments required"
**Fix**: This contract has NO constructor arguments. Leave field **EMPTY**.

**Success!** Someone already verified it. You're done! ✅
