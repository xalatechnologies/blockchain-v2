## 💡 Lessons Learned

### What Worked Well

1. **Whitelisting Strategy**: Whitelisting router and pair before adding liquidity allowed transfers while trading was disabled.

2. **WNOR Wrapping**: Using `addLiquidity()` with WNOR instead of `addLiquidityETH()` worked perfectly for NorSwap.

3. **Correct Lock Interface**: Using `createLock(token, amount, duration, description)` with duration in seconds, not timestamp.

4. **Step-by-Step Execution**: Breaking launch into 4 clear steps made debugging easier.

5. **Interface Creation**: Creating `IPancakeRouter02` and `IPancakeFactory` interfaces enabled compatibility.

### Common Pitfalls Avoided

1. ❌ **Trying to add liquidity before trading enabled** → ✅ Whitelist first
2. ❌ **Using addLiquidityETH on NorSwap** → ✅ Use addLiquidity with WNOR
3. ❌ **Passing timestamp to createLock** → ✅ Pass duration in seconds
4. ❌ **Hardcoded gas limits** → ✅ Estimate gas dynamically
5. ❌ **Forgetting to compile interfaces** → ✅ Always compile after adding contracts
