### Typography

#### Primary Typeface: **"Orbitron"** or **"Exo 2"**
- Clean, futuristic, technical
- Usage: Headings, logo, brand materials
- Weights: Medium (500), Bold (700), ExtraBold (800)

```css
font-family: 'Orbitron', 'Exo 2', 'Montserrat', sans-serif;
```

#### Secondary Typeface: **"Inter"** or **"IBM Plex Sans"**
- Readable, modern, professional
- Usage: Body text, descriptions, documentation
- Weights: Regular (400), Medium (500), SemiBold (600)

```css
font-family: 'Inter', 'IBM Plex Sans', system-ui, sans-serif;
```

#### Code/Technical Typeface: **"JetBrains Mono"** or **"Fira Code"**
- Monospace, ligature-enabled
- Usage: Code snippets, technical documentation, addresses
- Weights: Regular (400), Medium (500)

```css
font-family: 'JetBrains Mono', 'Fira Code', 'Monaco', monospace;
```

## Logo Usage Guidelines

### Do's ✅

- Use official logo files from brand assets repository
- Maintain minimum clear space around logo (equal to logo height)
- Use approved color variations only
- Scale proportionally (maintain aspect ratio)
- Place on appropriate background colors for contrast

### Don'ts ❌

- Don't stretch or distort the logo
- Don't change logo colors (except approved variations)
- Don't add effects (drop shadows, glows, etc.)
- Don't place on busy backgrounds without backdrop
- Don't recreate or modify the logo design

### Logo Clear Space

```
Minimum clear space: X = height of the hexagon

    X ←  → X
  ┌─────────────┐
X │             │ X
  │   [LOGO]    │
X │             │ X
  └─────────────┘
    X ←  → X
```

### Minimum Size

- **Digital**: 32px height (icon), 120px width (full logo)
- **Print**: 0.5 inch height minimum
- **Favicon**: 16x16, 32x32, 64x64 px
